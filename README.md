## 平台简介

盘家（PanJia）是一款面向中小型房地产中介企业的门店经营管理系统，基于 RuoYi 基础框架构建，围绕门店日常经营提供用户、角色、权限、部门、岗位等组织管理能力，后续将逐步扩展房源、业绩、佣金、合同、AI 经营助手等业务模块。

**品牌口号**：把店上的事，盘得明明白白

**部署方式**：本地部署 · 数据不出店

## 项目结构

```
panjia
├── panjia-admin      # 启动模块（Spring Boot 入口 + 模板 + Controller）
├── panjia-common     # 公共模块（工具类 + 实体 + 配置 + Shiro 基础）
├── panjia-framework  # 框架层（Shiro Realm + 登录服务 + 拦截器 + 日志）
├── panjia-system     # 系统模块（系统管理 + 系统监控 的 Service / Mapper / Domain）
├── panjia-quartz     # 定时任务模块
└── sql
    └── panjia.sql    # 数据库初始化脚本（PostgreSQL）
```

## 组织架构与权限模型

### 部门（当前最小骨架）

```
富房 (总部)
├── 龙湖店
├── 西派少城店
└── 租赁部
```

### 岗位（6 个）

公司股东 / 门店股东 / 店务秘书 / 业务组长 / 经纪人 / 见习经纪人

### 角色 × 数据范围（7 个）

| 角色 | 数据范围 | 说明 |
|---|---|---|
| 超级管理员 | 1 全公司 | 系统运维，全量权限 |
| 公司股东 | 1 全公司 | 看全公司数据 |
| 门店股东 | 2 自定义（参股勾选） | 仅看参股的门店，支持多参股 |
| 店务秘书 | 4 本部门及以下 | 负责整家门店日常，看本店全部 |
| 业务组长 | 3 本部门 | 看本组数据 |
| 经纪人 | 5 仅本人 | 看自己 |
| 见习经纪人 | 5 仅本人 | 看自己 |

数据范围由 Shiro + 自定义权限注解联合控制，`@DataScope(deptAlias = "d", userAlias = "u")` 按角色自动拼装 SQL 条件。

## 内置功能

### 系统管理

1. **用户管理**：系统用户配置，支持员工号、姓名、手机、邮箱、岗位、角色、部门多对多。
2. **部门管理**：公司/门店/部门/小组树结构，支持数据权限。
3. **岗位管理**：系统用户的职务配置。
4. **菜单管理**：菜单 / 操作权限 / 按钮权限标识配置。
5. **角色管理**：角色菜单权限分配 + 按机构的数据范围划分（自定义勾选参股门店）。
6. **字典管理**：用户性别、状态、数据范围、菜单类型/可见性、操作类型、日志状态、操作人类别、是否系统配置等固定数据维护。
7. **参数管理**：系统动态参数（如账户初始密码、主框架切换页、用户注册开关、提示内容等）。

### 系统监控

8. **在线用户**：当前系统中活跃的登录会话监控与强制下线。
9. **定时任务**：Cron 任务的在线增删改查、立即执行、暂停恢复，含执行结果日志。
10. **操作日志**：系统正常操作的日志记录与查询。
11. **登录日志**：系统登录记录与异常登录查询。

### 已裁剪功能

## 快速开始

### 一、环境准备

- JDK 17+
- Maven 3.8+
- PostgreSQL 12+
- Docker（可选，快速启动 Postgres）

### 二、数据库初始化

```bash
# 1. 创建数据库（PostgreSQL）
CREATE DATABASE panjia OWNER panjia;

# 2. 导入初始化脚本（含表结构 + 初始数据）
psql -U panjia -d panjia -f sql/panjia.sql
```

### 三、修改数据源

编辑 `panjia-admin/src/main/resources/application-druid.yml`，填入 PostgreSQL 的地址、用户名、密码。

### 四、编译 & 启动

```bash
# 编译
mvn clean package -DskipTests

# 启动
java -jar panjia-admin/target/panjia-admin.jar
```

访问：http://127.0.0.1:8080/

默认进入登录页：**员工号 0001 / 口令 admin123**。
